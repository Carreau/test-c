SQLite Database Research Tool

Note: The sample database will load automatically using HTTP VFS with range requests. This means only the needed parts of the database are fetched, not the entire file. The database contains employees, products, and orders data.

Example Queries (for sample.db):

SELECT name FROM sqlite_master WHERE type='table'; - List all tables
SELECT * FROM employees; - Show all employees
SELECT * FROM products WHERE price < 100; - Products under $100
SELECT ... FROM employees JOIN orders ... - Employee orders with totals
SELECT ... GROUP BY department - Average salary by department
